# 程式碼健康檢查（2026-09-07）

## 範圍

檢查啟動、資料驗證／匯入與保存、插件協調、遊戲事件、回應排程、語癖、動畫／更衣室、動作清單／搜尋、設定頁、載入器與建置／預覽腳本。離線測試與預覽不等同於真實遊戲及所有第三方插件組合的完整驗證。

## 本次修正

- 抽離設定頁 CSS、搜尋載入控制器；事件綁定按功能拆分。加入 Prettier 與格式檢查，保留可讀原始碼。
- 搜尋卡片使用 `hidden` 與專屬 CSS，移除 inline `!important` 覆蓋。選定部位才讀翻譯，同次面板載入沿用已完成索引。
- 非同步載入採用請求序號，取消關閉面板、語系變更及快速 A→B→A 切換的過期結果。
- 移除未使用的舊 Canvas 設定頁、無作用的訪客離開攔截，以及為無 DOM 測試環境存在的替代頁面。測試改用 DOM stub 驗證實際設定頁註冊，互動另外在瀏覽器驗證。
- 移除改寫外部 LCE 原始碼的連接腳本。保留 ModSDK 正式 hooks 與公開接管 API，未改寫使用者的 LCE 倉庫。
- 停止模組時清除初始化與監控計時器、取消資料訂閱；通知計時器隨面板卸載清理。共享 I18N 服務仍供其他插件使用。
- 初始化時記錄當前畫面，避免第一次監控誤取消剛啟動的回應。房間同步失敗不再送出進房事件。
- 舊 consumer 的取消訂閱不再移除同名的新註冊。
- 新舊動畫輸入共用同一執行流程；每幀只重建人物一次，取消後晚到的回呼不再改動裝備。單一還原失敗不阻止其他動畫清理。
- 驗證設定不再為取得欄位名稱生成整套預設人格與隨機 ID。版本號以 package.json 為單一來源。

## 呼叫流程

遊戲事件 → 建立事件資料 → 有效性與規則篩選 → 回應抽選 → 延遲／主回應排程 → 執行前再次檢查 → BCX 檢查 → 遊戲原生發言、動作或外觀 API。

部位選取 → 載入控制器／快取 → 分批讀取遊戲翻譯 → 建立繁簡搜尋索引 → 建立卡片一次 → 輸入時比對並切換可見性。

## 驗證與維護

`npm run build`、`npm test`、`npm run format:check`。測試涵蓋載入／取消競態、房間同步失敗、訂閱替換、停止監控、動畫共用畫格／取消、搜尋與既有規則功能。瀏覽器預覽確認繁簡混合、英文、篩選後全選及特殊動作面板。

設定頁的 HTML 模板仍集中於 dom-settings.js，檔案偏大；目前按函式分責，後續新增大型頁面宜再獨立模組。CSS 的既有元件優先級仍有 `!important`，本次移除的是搜尋顯示補救，不宣稱全站樣式已完全重寫。遊戲權限、第三方 hooks 與更衣室完整操作仍需遊戲內驗證。
